# Digital Product Hub v3.0 — Frontend

Frontend statis (GitHub Pages) untuk portal Kelas & Aplikasi. Backend: Google Apps Script (`Kode.gs`, dipasang terpisah).

## Struktur
```
index.html        ← halaman tunggal (SPA)
css/base.css      ← token desain (sama dengan v2)
css/app.css       ← komponen v3
js/config.js      ← ISI GAS_URL DI SINI
js/core.js        ← API, cache, router
js/public.js      ← Open Access, login, redeem
js/member.js      ← portal member
js/admin*.js      ← panel Superadmin
```

## Alamat penting
- Halaman publik: `https://USERNAME.github.io/REPO/#/explore`
- Login: `https://USERNAME.github.io/REPO/#/login`

Panduan lengkap ada di `PANDUAN-INSTALASI.md`.
